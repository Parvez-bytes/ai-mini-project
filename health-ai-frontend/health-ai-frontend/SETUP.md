# Setup — Frontend Part 1

## Exact commands

```bash
npm install
npm run dev
```

Then open the URL shown by Vite, normally:

```text
http://localhost:5173
```

## Notes

- This is **FRONTEND PART 1** of the AI-Powered Preventive Healthcare Recommendation Engine.
- All analysis, recommendations, history, trends, simulator results, and assistant replies are mock/frontend behavior.
- Profile data and the mock login session use browser `localStorage`.
- Backend services, MongoDB, Python/FastAPI, ML models, real authentication, external APIs, and API keys will be added in Part 2.
